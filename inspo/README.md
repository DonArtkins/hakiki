# UI Inspiration (inspo/)

Screenshots and references of UI/UX we desire. Agents MUST consult `inspo/` before
building UI, alongside `design.md`, `docs/07_BRANDING_AND_DESIGN_SYSTEM.md` and the UI
registry. Borrow qualities (grammar, anatomy, tokens), never the look itself, and never
another brand's identity. These are reference inputs, not product screens to copy.

Copied 2026-10-27 from the sababisha-culture inspo set at the operator's direction;
